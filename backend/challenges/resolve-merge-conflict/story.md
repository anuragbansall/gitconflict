# ⚔️ Resolve the Merge Conflict

Two developers worked on the same `login()` function at the same time.

One developer improved the authentication message.

The other added a success log.

When you tried to merge the feature branch into `main`, Git couldn't decide which version to keep.

## Your Task

Resolve the merge conflict **without losing either improvement**.

The final version of `app.js` should:

- Print **"User authenticated"**
- Print **"Login successful"**
- Contain **no conflict markers**

After resolving the conflict:

1. Stage the file.
2. Complete the merge.
